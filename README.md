# Personal Expense Tracker

## Project Overview

Personal Expense Tracker is a web-based application developed using Flask and SQLite. It helps users manage daily expenses, set a custom budget, monitor spending habits, and track remaining balance through a simple and user-friendly dashboard.

---

## Problem Statement

Managing daily expenses manually is difficult and often results in poor financial planning. This project provides a digital solution that allows users to record expenses, categorize spending, set budgets, and monitor financial activities efficiently.

---

## Objectives

- Record daily expenses
- Set a customizable budget
- Track total spending
- Monitor remaining balance
- Search expenses easily
- Improve personal financial management
